🚢 Titanic Dataset Analysis
📌 Project Title

Titanic Dataset Analysis Using Python

📖 Project Description

This project analyzes the famous Titanic dataset to understand the factors that influenced passenger survival. The dataset contains information about passengers such as age, gender, class, fare, and survival status.

The goal of this project is to perform data cleaning, exploration, visualization, and extract meaningful insights using Python libraries.

🎯 Objectives

To understand the structure of the Titanic dataset

To clean and preprocess missing data

To analyze survival rates based on different features

To visualize important patterns in the dataset

To draw conclusions from the analysis

📂 Dataset Information

The dataset includes the following key columns:

PassengerId

Survived

Pclass

Name

Sex

Age

SibSp

🔎 Analysis Performed

Data Cleaning (Handling missing values)

Statistical Summary

Survival Rate Analysis

Gender-wise Survival Analysis

Class-wise Survival Analysis

Age Distribution Analysis

Correlation Heatmap Visualization

📊 Key Findings

Female passengers had a higher survival rate than male passengers.

First-class passengers had better survival chances.

Younger passengers had relatively higher survival rates.

Fare and passenger class influenced survival probability.

▶️ How to Run the Project

Install required libraries:

pip install numpy pandas matplotlib seaborn

Open Jupyter Notebook:

jupyter notebook

Run the Titanic analysis notebook.
